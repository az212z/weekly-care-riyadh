# ذا ويكلي كير — Website concept

Arabic/English responsive static website.

Live preview: https://az212z.github.io/weekly-care-riyadh/

## Features
- Searchable service catalog and local interest list.
- Original business photographs and native accessible lightbox.
- Validated enquiry composer that opens WhatsApp; no messages are sent automatically.
- Original booking destination where available.
- No backend, no invented payment or booking confirmation.
- No tracking; localStorage stores preferences only.

## Hosting
GitHub Pages: deploy main branch from root. `.nojekyll` included. Run locally with `python3 -m http.server 8000`.

## Launch review
This public preview is a proposal, not owner endorsement. Search engine indexing is disabled. Before official transfer, obtain owner approval of identity, photographs, contact information, prices and service availability; set the final domain and update canonical/OG metadata. External booking availability and payment are managed by the business on Fresha.
